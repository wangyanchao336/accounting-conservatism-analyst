# accounting-conservatism-analyst

资深会计学者（财务报告稳健性分析师）—— Claude Code 技能。

阅读企业年度报告（财务报表、附注、MD&A），从会计政策、会计估计、管理层表述等多维度判断财务报告的稳健程度，将企业分类为**稳健 / 中性 / 不稳健**。

## 安装

将本目录复制到 `~/.claude/skills/accounting-conservatism-analyst/`，Claude Code 会自动加载。

或直接导入 `.skill` 文件：从 [Releases](https://github.com/aeroa/accounting-conservatism-analyst/releases) 下载 `accounting-conservatism-analyst.skill`。

## 使用方法

向 Claude Code 提供企业年报（PDF 文件或粘贴文本），如：

> 请分析这份宁德时代 2024 年年报的财务稳健程度

技能将自动触发，按 6 个会计维度 + 管理层基调 + 警示信号进行全面分析，输出结构化 JSON。

## 分析框架

| 维度 | 内容 |
|------|------|
| 研发费用确认 | 资本化率、阶段划分标准 |
| 商业信用与收入确认 | 信用期、收入确认时点、渠道压货 |
| 坏账计提比例 | 账龄计提率、单项计提、ECL 模型 |
| 固定资产折旧 | 折旧年限、残值率、减值测试 |
| 存货计价与跌价准备 | 计价方法、跌价比例、库龄结构 |
| 资产减值（商誉等） | 减值测试假设、减值频率 |
| MD&A 基调 | 风险披露坦率度、非 GAAP 使用 |
| 其他警示信号 | 审计师更换、关联交易、或有负债等 |

## 分类标准

- **稳健** — ≥80% 维度表现为稳健，无明确不稳健信号
- **中性** — 介于两者之间，报告公允但非极端保守
- **不稳健** — ≥2 个不稳健维度，或单一重大红旗信号
